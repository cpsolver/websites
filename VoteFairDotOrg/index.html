Social media

The r/EndFPTP (end first-past-the-post) subreddit (within Reddit) gives you access to election-method reform experts.  Expect controversy because many better election systems are possible.

r/EndFPTP subreddit

Election-methods wiki

Electowiki describes the math behind many election methods.  It includes new election methods that are not yet in Wikipedia because there is no governmental funding for academic research about better election methods.

Electowiki

RCTab Plus election software

Election-grade software that adds two options to the RCTab software supported by the Ranked Choice Voting Resource Center.  These options implement a simple plus version of ranked choice voting.

RCTab Plus software

A long (40-minute) video created at the request of election-method researchers who asked "What do you think we should know?"  The first few minutes clarify the transition from creative-problem-solving author to election-method expert.

Old VoteFair.org website

The older home page for this website, with content that has been promoting election-method reform for three decades.  It includes the VoteFair ranking survey service, and the long-ago VoteFair American Idol polls.

The Goat Spitting Secret

A first step toward creating a full-cast audiobook that unsuccessfully attempted to convey important election-reform concepts and economic-reform concepts within a comedic entertaining story.  This is just the non-audio (text only) book version of the dialog.

The Goat Spitting Secret

RCIPE software

Open-source software that implements the election method named Ranked Choice Including Pairwise Elimination (RCIPE).  It implements both the single-winner and proportional (STV-like) versions.

RCIPE software

VoteFair Negotiation Tool

Open-source software that implements VoteFair negotiation ranking.  It's for future use when legislatures choose to improve how they vote on proposed legislation.

VoteFair Negotiation Tool
